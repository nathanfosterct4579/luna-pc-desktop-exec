## Overview

Luna PC provides a Windows desktop workflow for loading and running Roblox Lua scripts. Alongside its execution tools, the application includes a script hub and an automatic update system intended to help keep the software current as new builds and Roblox changes are released.

Rather than presenting a large or complicated workspace, Luna PC focuses on quick script access and a lightweight interface. Users can run scripts individually or in batches, maintain queued items between sessions, and use the included debugging tools to review script behavior.
